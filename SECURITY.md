# Beveiligingsbeleid

## Een kwetsbaarheid melden

Meld beveiligingsproblemen **niet** via een publiek issue.

Gebruik in plaats daarvan GitHub's private meldingsformulier via
[Security → Report a vulnerability](https://github.com/frankgraave/subglance/security/advisories/new).

Je krijgt binnen 72 uur een ontvangstbevestiging. Zodra er een oplossing is,
wordt die gepubliceerd met vermelding van de melder — tenzij je anoniem wilt
blijven.

## Ondersteunde versies

Zolang het project in vroege ontwikkeling is, worden alleen fixes op de laatste
versie van `main` uitgebracht.
