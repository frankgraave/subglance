# Keyboard commands

Open the command menu with **Ctrl/Cmd+K** or the command button in the masthead.
Search monitor names and targets, use the arrow keys to move through results,
and press Enter to open one. Matching monitors are not capped at the first page.

Editors and administrators can pause or resume a monitor and open Add monitor.
Everyone can navigate to Dashboard, Monitors, Incidents, Notifications and
Settings, or choose **Light**, **Dark** or **System** through the same saved
preference as the theme control. Read-only accounts receive no write commands.
Failures stay visible rather than masquerading as successful actions.

Tab stays inside the open menu. Escape closes only the command menu and returns
focus; it does not discard a form underneath. Choosing a destination still
uses the application's unsaved-form confirmation. Closing the menu while a
pause request is in progress does not undo the server operation: its result
still refreshes the screen. Signing out ends the session and clears that state.

Ctrl/Cmd+B remains the sidebar shortcut. Ordinary controls remain reachable
with Tab; the command menu does not replace their keyboard behavior.
