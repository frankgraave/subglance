SubGlance — living style guide

Every value on this page is read out of web/src/styles/tokens.css when the page is generated, and this page loads that same file as its stylesheet. There is no second copy to drift. A token that changes changes here; a token that is deleted disappears from the table.

This page is not the guarantee. Documentation that is only read when someone remembers to read it is how a design system drifts in the first place — this repository already had 1797 lines of design documentation while 88 loose pixel values accumulated across 26 stylesheets. The guarantee is web/src/styles/tokens.test.ts, which fails the build on a literal colour, size, type role, leading, tracking, spacing, radius, border, depth value or breakpoint. This page exists so a human can see what the guards enforce, and so a reviewer can tell whether a new rung deserves to exist. When the two disagree, the test wins and the page is the thing that is broken.

Components

The real components, rendered by React from web/src/styleguide-specimens.tsx against the built stylesheet. Not drawings of them: the markup and class names here are the ones the product ships, so a chip that looks wrong on this page looks wrong in the product. Each carries the rule it exists to keep.

Value

A measurement. Tabular figures so a column lines up. A zero reading dims; an absent reading renders nothing, because nothing and zero are different statements. A caveat draws the dotted underline and is read aloud. web/src/components/Value.tsx

Buttons

The accent fills controls and nothing else. A primary action gets the accent border, and carries a + when it adds the thing the surface it sits on is a list of. A compact row action sits in a 26px square with its name in aria-label. Delete is a glyph like its neighbours: the bin carries destructive in its shape, so it survives greyscale where red alone would not, and the confirmation that makes you type the name is what buys back the pause the word used to. web/src/monitors/monitors.css, web/src/monitors/inventory.css

Segmented control

An 8px shell around 6px segments, concentric. The selected segment takes the accent. The group carries a label for assistive technology even when every segment is a word. web/src/components/SegmentedControl.tsx

Icon tile

The 24px tile beside a card title. Its border adds optical weight, which is why the gap to the title is a half-step wider than the grid would give. web/src/components/IconTile.tsx

Masthead and toolbar

Two bars, and which one a control belongs in is decided by a single question: is it true on every screen? The masthead holds what is — the sidebar toggle, search, the layout switcher, the theme. It never changes as you navigate, so it stays readable without being re-read. The toolbar below holds what is true of this screen only, and disappears on screens with nothing to put in it rather than sitting there empty. An action that operates on one kind of thing fails the question: adding a monitor is a monitors action, so it lives in the header of the card it adds to, not in chrome that is also present on Notifications. web/src/shell/Topbar.tsx, web/src/shell/PageToolbar.tsx

Type

Every size is paired with a leading, and the guard asserts the pairing in both directions: a role without a leading fails, and a leading without a role fails. Specimens render at the real value.

SpecimenTokenSize / leadingWhat it is for
Ag --type-page 24px / 32px Type. Six roles, one scale — §2.5. A component never spells out a font size, for the same reason it never spells out a colour: "make everything a step larger" has to be one edit, not sixty, and sixty hand-tuned sizes
moredrift out of proportion the first time one of them is touched. Nothing here is below 12px; smaller than that stops being readable at a glance, which is the entire product. The column ladder

Five rungs at 8 x the Fibonacci sequence, so every data column in the product is related to every other by the same ratio instead of chosen one table at a time. The ratio column is the point: each rung is phi (1.618) times the one below, to within 1.2% at its worst step. They are Fibonacci rather than phi exactly because phi lands on a fractional pixel — 64 x 1.618 = 103.55 — and a border on a half pixel renders differently per device pixel ratio. A column takes the smallest rung its widest label fits in; data truncates.

Breakpoints

Documented here, enforced as literals. A custom property inside a media query never resolves — verified in Chromium, not assumed — and it fails silently, so the block is simply dropped and the layout is quietly wrong at one width. The guard asserts every @media width in the product is one of these, and that none of them is written as var().
