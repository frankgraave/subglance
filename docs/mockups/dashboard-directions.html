Rows. One row per monitor, sorted so anything broken is already at the top. The row is the unit: name, live heartbeat, latency, uptime. Made for a laptop where you scan, then click through.

Cards. For the second screen on your desk. Bigger LEDs, fewer words, status readable from across the room. Cards with a problem take a coloured edge; healthy ones stay quiet.

Compact. Grouped by client or environment, one compressed line each. Built for 100+ monitors where the only question is whether anything is red. Group header carries a row of LEDs so a collapsed group still tells you.
