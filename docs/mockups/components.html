Card 12px radius and a 6px inset; panel 8px, its own edge, and the raised rung. The gap between panels equals the card's padding, so a panel is as far from its neighbour as from the edge.
Why there is no wrapper
The tempting shape is a container holding the list, with the panels inside it. It costs a third surface and a second inset. Keep the list wrapper transparent: the rows already supply the panel fill, edge and shadow. The card supplies the frame.
The rule that falls out of it: if a thing already has an edge, it does not need a box around it. A list of panels is a list; the card is already the container.
Depth ladder
flat is a stated decision, not an absence — it is what a card takes. raised is what a panel takes. Both come directly from the shared shadow ladder, so changing that ladder changes this example and the product together.
