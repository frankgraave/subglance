# Bijdragen aan Subglance

Bedankt voor je interesse. Hieronder staat wat je moet weten voordat je een
pull request opent.

## Contributor License Agreement (CLA)

Subglance wordt uitgebracht onder de AGPL-3.0. Het auteursrecht op de code
ligt bij een enkele partij.
auteursrecht op de codebase bij één partij liggen.

Daarom vragen we iedere bijdrager om de [CLA](CLA.md) te aanvaarden. Je behoudt
het auteursrecht op je eigen werk, maar geeft Frank Graave het recht om je
bijdrage ook onder andere licenties uit te brengen.

Aanvaarden doe je door in je eerste pull request te bevestigen:

```
Ik heb de CLA gelezen en ga akkoord.
```

Zonder die bevestiging kan een pull request niet worden samengevoegd.

## Werkwijze

1. Open eerst een issue voor grotere wijzigingen, zodat we de aanpak kunnen
   afstemmen voordat je tijd investeert.
2. Fork de repository en werk op een aparte branch.
3. Houd een pull request beperkt tot één onderwerp.
4. Beschrijf in de pull request wát je verandert en waaróm.

## Bugs melden

Open een issue met:

- wat je verwachtte dat er zou gebeuren;
- wat er in plaats daarvan gebeurde;
- de stappen om het te reproduceren;
- je versie en omgeving.

## Beveiligingsproblemen

Meld kwetsbaarheden **niet** via een publiek issue. Zie [SECURITY.md](SECURITY.md).
