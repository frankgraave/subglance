## Hard-won lessons (do not relearn these)

- Long sessions cost ~3.3x per call versus short ones. Finish one issue, stop.
- A failing test is a hypothesis. Verify a fix by breaking it and check HOW it
  failed: a build error proves nothing. Sabotage the logic, not the types.
- The terminal tool blocks a command whose TEXT resembles a long-lived watcher,
  even a heredoc merely writing a file that mentions one. Reword the file.
- Tailwind v4 needs `@theme inline`; plain `@theme` freezes one theme.
- Absence and zero are different facts on every read path.
- Enum values live in internal/store/migrations/0001_init.sql CHECK constraints.
- Go helpers: seedMonitor, testServerWithDB, seedUser, doJSON, openTestDB,
  and `contains` (already declared in validate_test.go — do not redeclare).
- docs/openapi.yaml is drift-tested by openapi_test.go: a behaviour change that
  skips the spec fails the build. Prose in the spec also describes behaviour and
  goes stale silently — grep it for the old wording, not just the status codes.
- jsdom has no layout: getBoundingClientRect is all zeroes. HeartbeatBar needs
  an explicit `width` prop in tests or it renders empty.
- `getByRole("table")` is ambiguous: every HeartbeatBar renders its own sr-only
  table. Match the monitor table by its caption's accessible name.
- oxlint react(set-state-in-effect) fires on any setState in an effect, and
  only-export-components fires on a non-component export from a .tsx.
