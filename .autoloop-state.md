## Hard-won lessons (do not relearn these)

- Long sessions cost ~3.3x per call versus short ones. Finish one issue, stop.
- A failing test is a hypothesis. Verify a fix by breaking it and check HOW it
  failed: a build error proves nothing. Sabotage the data, not the types.
- The terminal tool refuses commands whose TEXT looks like a dev server (a
  README line with `npm run dev` suffices). Write such files via python.
- `json.load` chokes on JSONC comments in tsconfig — write those files whole.
- Tailwind v4 needs `@theme inline`; plain `@theme` freezes one theme at build.
- Vite's react-ts template ships unused assets and a boilerplate README. Delete.
- Absence and zero are different facts on every read path.
- Enum values live in migrations/0001_init.sql CHECK constraints. Read them.
- Helpers exist: seedMonitor, testServerWithDB, seedUser, doJSON, openTestDB.
