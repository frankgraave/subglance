## Hard-won lessons (do not relearn these)

- Long sessions cost ~3.3x per call versus short ones. Finish one issue, stop.
- A failing test is a hypothesis. Verify a fix by breaking it and check HOW it
  failed: a build error proves nothing. Sabotage the logic, not the types.
- The terminal tool blocks a command whose TEXT resembles a long-lived watcher.
- Tailwind v4 needs `@theme inline`; plain `@theme` freezes one theme.
- Absence and zero are different facts on every read path.
- Enum values live in internal/store/migrations/0001_init.sql CHECK constraints.
- Go helpers: seedMonitor, testServerWithDB, seedUser, doJSON, openTestDB, and
  `contains` (already in validate_test.go — do not redeclare).
- docs/openapi.yaml is drift-tested by openapi_test.go; its prose goes stale
  silently too — grep it for old wording, not just status codes.
- jsdom: no layout (HeartbeatBar needs an explicit `width`), no `matchMedia`
  (stub it), and `import.meta.url` is an http URL there — a test that reads a
  file from disk needs its own `@vitest-environment node` file.
- Every HeartbeatBar renders an sr-only table with a "Latency" header, so a
  loose getByText inside a card or row matches the wrong node. Scope queries to
  a class (`.mon-card-fact dd`) or match the caption's name.
- oxlint react(set-state-in-effect) fires on any setState in an effect;
  `useSyncExternalStore` is the way to read an external value instead.
