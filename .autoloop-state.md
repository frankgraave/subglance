**Serving the UI**: the frontend builds into `internal/webui/dist` (NOT
web/dist) and `internal/webui` embeds it with `//go:embed all:dist`. Its
handler is the catch-all route `/` in `routes()`, registered for every method
via `anyMethod` (""). Unknown page path -> index.html; unknown `/api` path ->
JSON 404; missing hashed asset -> real 404; non-GET/HEAD -> 405. The committed
`internal/webui/dist/.gitkeep` keeps `go build` working without Node: do not
delete it, and keep `emptyOutDir: false` in the bundler config. `make dist` =
web-build + build. `route.documented()` is why `/` is in the route table but
not in docs/openapi.yaml.

**API**: `Server.requireMonitor` in `internal/api/monitors.go` is the single
place that answers "does this monitor exist" for sub-resource reads. All four
(/heartbeats, /incidents, /uptime, /channels) call it. `sql.ErrNoRows` -> 404,
anything else -> 500. A fifth sub-resource must call it and be added to
`monitorSubresourcePaths` in `internal/api/monitor_subresource_test.go`.
`GET /api/v1/monitors?heartbeats=N` embeds each monitor's beats (oldest first)
via `store.RecentHeartbeatsForAll` — one window-function query, not N+1.

**Frontend in `web/`**: React 19, Tailwind v4, oxlint, vitest. Root Makefile:

`web/src/heartbeat/`: `model.ts` (pure geometry) + `HeartbeatBar.tsx`.
`web/src/monitors/`: `model.ts`, `types.ts`, `format.ts`, `Unknown.tsx`,

## Hard-won lessons (do not relearn these)

- Long sessions cost ~3.3x per call versus short ones. Finish one issue, stop.
- A failing test is a hypothesis. Verify a fix by breaking it and check HOW it
  failed: a build error proves nothing. Sabotage the logic, not the types.
- The terminal tool rejects a heredoc whose text merely resembles a long-lived
  watcher (the bundler's name in a comment did it). Write such files through a
  python heredoc, or use a placeholder and substitute it.
- git cannot un-ignore a file inside an ignored directory: un-ignore the
  directory first (`!dir/`), then `dir/*`, then `!dir/keep`.
- Tailwind v4 needs `@theme inline`; plain `@theme` freezes one theme.
- Absence and zero are different facts on every read path.
- Enum values live in internal/store/migrations/0001_init.sql CHECK constraints.
- Go helpers: seedMonitor, testServerWithDB, seedUser, doJSON, openTestDB and
  `contains` (already in validate_test.go — do not redeclare).
- docs/openapi.yaml is drift-tested by openapi_test.go; its prose goes stale
  silently too — grep it for old wording, not just status codes.
- jsdom: no layout (HeartbeatBar needs an explicit `width`), no `matchMedia`
  (stub it), and `import.meta.url` is an http URL there.
- Every HeartbeatBar renders an sr-only table with a "Latency" header, so a
  loose getByText inside a card or row matches the wrong node.
- oxlint react(set-state-in-effect) fires on any setState in an effect;
  `useSyncExternalStore` reads an external value instead.
